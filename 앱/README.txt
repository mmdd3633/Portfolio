# FIEVA 앱

시각·청각장애인의 초기 화재 대피를 돕기 위해 제작한 실내 대피 지원 애플리케이션입니다.

사용자 앱은 BLE 비콘 RSSI와 스마트폰 센서 기반 PDR을 결합하여 사용자의 대략적인 실내 위치를 추정합니다. 화재 발생 지점을 피하는 대피 경로를 계산하고, 화면·음성·진동으로 이동 방향과 위험 상황을 안내합니다.

관리자 앱은 Firebase를 통해 화재 테스트를 제어하고, 사용자의 위치와 특정 구역의 고립 위험을 모니터링합니다.

## 주요 기능

- BLE RSSI와 PDR 기반 실내 위치 추정
- 화재 지점을 제외한 대피 경로 탐색
- 화면, 음성(TTS), 진동 기반 대피 안내
- Firebase 기반 사용자 위치 공유 및 관리자 모니터링
- 관리자 화재 테스트 시작·종료 제어

## 기술

Flutter/Dart, Firebase Cloud Firestore, FCM, BLE, 스마트폰 센서, TTS

본 프로젝트는 실험 및 연구 목적의 프로토타입이며, 실제 소방 안전 설비를 대체하지 않습니다.
